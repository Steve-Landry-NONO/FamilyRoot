📊 Métriques du Flow

  • Écrans totaux MVP : 24 écrans
  • Points de décision : 5 embranchements
  • Chemins critiques : 3 (inscription, connexion, invitation)
  • Clics max pour action clé : 4 (inscription → dashboard)

🎯 Parcours Critiques

  • Nouveau utilisateur : Splash → Onboarding → Inscription → Confirmation → Créer famille → Dashboard
  • Utilisateur existant : Splash → Login → Dashboard
  • Invité : Splash → Onboarding → Rejoindre (code) → Dashboard
  • Consultation arbre : Dashboard → Arbre → Sélection membre → Profil

⚠️ Points d'Attention UX

  • Empty states : Arbre vide, Notifications vides, Calendrier vide — doivent guider l'utilisateur vers l'action
  • Erreurs : Connexion échouée, Code invalide, Réseau — doivent proposer une solution
  • Confirmation email : Permettre saisie code OU clic lien — flexibilité
  • Multi-familles : Switch rapide depuis header dashboard
